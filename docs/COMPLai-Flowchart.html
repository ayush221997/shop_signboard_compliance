1. Request & processing pipeline

From upload to POST /api/ocr response. Vision is called without language_hints; state_code only drives rules.

flowchart TB U[("Upload image + state/UT in form")] --> D{Decode BGR} D --> S["Upscale if long edge < 1024 px"] S --> P["prepare_bgr_for_document_ocr · optional prebinarize"] P --> V[("Google Cloud Vision: DOCUMENT_TEXT_DETECTION + LOGO")] V --> T["Build blocks, GSTIN, translations"] T --> G[("SignboardGeometryAgent: 1024×1024 warp + threshed ink by script")] G --> R[("get_rules_for_state: required_scripts + min % ")] R --> E[("evaluate_compliance + governance merge")] E --> O[("OcrResult JSON: text, geometry, compliance, audit_id")]

2. COMPLai compliance checks (order)

Early exits prevent false passes; ratio tests run only when script allowlists pass.

flowchart TB A["Location rules and threshed ratios present?"] -->|no| PEND["pending or uncertain"] A -->|yes| B["Aggregate ink by BCP-47 base script"] B --> C["Dominant script in state allowlist?"] C -->|no| F1["FAIL — dominant / jurisdiction"] C -->|yes| D["Every script with over 1.5 percent ink in allowlist?"] D -->|no| F2["FAIL — material ink outside allowlist"] D -->|yes| M["Monolingual exemption for min percent?"] M -->|yes| OK1["PASS — monolingual path"] M -->|no| R["Required primary share vs state minimum percent"] R -->|ok| OK2["PASS — ratio met"] R -->|low| F3["FAIL — primary share too low"]
